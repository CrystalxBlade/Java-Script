# JavaScript Objects

### An object is a collection of related data and functionality.

### Objects store data using:

```text
key: value
```
## Example 

```
let player = {
    name: "Blade",
    age: 24,
    game: "Hollow Knight"
};

```
## Important Object Methods

| Method             | Purpose                          |
| ------------------ | -------------------------------- |
| `Object.keys()`    | Returns property names           |
| `Object.values()`  | Returns property values          |
| `Object.entries()` | Returns key-value pairs          |
| `Object.assign()`  | Copies properties                |
| `Object.freeze()`  | Prevents all changes             |
| `Object.seal()`    | Prevents adding and deleting     |
| `hasOwnProperty()` | Checks direct property ownership |
