# 18 - ES6

## What is ES6?

ES6 stands for **ECMAScript 2015**.

It was a major update to JavaScript that introduced many features that are now considered standard modern JavaScript.

Some important ES6 features are:

- let
- const
- Arrow functions
- Template literals
- Default parameters
- Rest parameters
- Spread syntax
- Destructuring
- Enhanced object literals
- Classes
- Modules
- Map
- Set
- Symbol
- Promises
- for...of

ES6 made JavaScript easier to write and introduced many features that are still heavily used today.
