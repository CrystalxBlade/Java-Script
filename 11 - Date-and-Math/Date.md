# JavaScript Date and Math

JavaScript provides built-in objects for working with dates, times, calculations, and random numbers.

The two main objects covered in this folder are:

1. `Date`
2. `Math`


---

# Part 1: Date Object

The `Date` object is used to work with:

- Current date
- Current time
- Specific dates
- Date differences
- Date formatting
- Date comparisons
