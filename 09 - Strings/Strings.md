# JavaScript Strings

### A string is a sequence of characters used to represent text.

## Examples:

```javascript
let name = "Blade";
let game = 'Hollow Knight';
let character = `Knight`;
```

### JavaScript supports three ways of creating strings:

- Double quotes " "
- Single quotes ' '
- Template literals ` `


| Method / Property | Purpose                                   |
| ----------------- | ----------------------------------------- |
| `length`          | Returns string length                     |
| `charAt()`        | Gets character at index                   |
| `at()`            | Gets character, supports negative indexes |
| `toUpperCase()`   | Converts to uppercase                     |
| `toLowerCase()`   | Converts to lowercase                     |
| `trim()`          | Removes surrounding whitespace            |
| `includes()`      | Checks if text exists                     |
| `startsWith()`    | Checks beginning                          |
| `endsWith()`      | Checks ending                             |
| `indexOf()`       | Finds first occurrence                    |
| `lastIndexOf()`   | Finds last occurrence                     |
| `slice()`         | Extracts part of string                   |
| `substring()`     | Extracts part of string                   |
| `replace()`       | Replaces first match                      |
| `replaceAll()`    | Replaces all matches                      |
| `split()`         | Converts string to array                  |
| `concat()`        | Joins strings                             |
| `repeat()`        | Repeats string                            |
| `padStart()`      | Adds characters at beginning              |
| `padEnd()`        | Adds characters at end                    |
