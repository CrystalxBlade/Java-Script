# JavaScript Error Handling

Error handling allows JavaScript programs to detect and handle problems instead of allowing the program to fail unexpectedly.

JavaScript provides several tools for handling errors:

- `try`
- `catch`
- `finally`
- `throw`
- `Error`
- Built-in error types
- Custom errors

---
