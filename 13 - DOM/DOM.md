# JavaScript DOM

DOM stands for:

**Document Object Model**

The DOM is the browser's representation of an HTML document.

It allows JavaScript to interact with HTML elements.

With the DOM, JavaScript can:

- Find HTML elements
- Read HTML content
- Change text
- Change HTML
- Change CSS
- Change attributes
- Add elements
- Remove elements
- Create elements
- Navigate between elements

## Important DOM Manipulation Properties

| Method                     | What it does                     |
| -------------------------- | -------------------------------- |
| `getElementById()`         | Finds an element by ID           |
| `querySelector()`          | Finds the first matching element |
| `querySelectorAll()`       | Finds all matching elements      |
| `getElementsByClassName()` | Finds elements by class          |
| `getElementsByTagName()`   | Finds elements by tag            |


## Important DOM Manipulation Properties

| Property      | Purpose                   |
| ------------- | ------------------------- |
| `textContent` | Read/change text          |
| `innerText`   | Read/change visible text  |
| `innerHTML`   | Read/change HTML          |
| `style`       | Change inline CSS         |
| `className`   | Read/change classes       |
| `classList`   | Manage individual classes |
| `value`       | Read/change form value    |


## Important DOM Creation Methods

| Method             | Purpose                       |
| ------------------ | ----------------------------- |
| `createElement()`  | Creates an HTML element       |
| `createTextNode()` | Creates a text node           |
| `append()`         | Adds content at the end       |
| `prepend()`        | Adds content at the beginning |
| `appendChild()`    | Adds a child node             |
| `remove()`         | Removes an element            |
| `removeChild()`    | Removes a child               |


## DOM Navigation Properties

| Property                 | Purpose               |
| ------------------------ | --------------------- |
| `parentElement`          | Gets parent           |
| `children`               | Gets child elements   |
| `firstElementChild`      | Gets first child      |
| `lastElementChild`       | Gets last child       |
| `nextElementSibling`     | Gets next sibling     |
| `previousElementSibling` | Gets previous sibling |
