# JavaScript Timers

JavaScript timers allow code to execute:

- after a delay
- repeatedly after a specific interval
- after a certain amount of time has passed

The main timer functions are:

- `setTimeout()`
- `clearTimeout()`
- `setInterval()`
- `clearInterval()`

Timers are extremely useful for:

- countdowns
- clocks
- animations
- notifications
- delayed messages
- auto-saving
- games
- temporary UI messages
- polling
- time-based applications
