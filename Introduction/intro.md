# JavaScript Introduction

## What is JavaScript?

JavaScript is a high-level, interpreted programming language used to make web pages interactive and dynamic.

With JavaScript, you can:

- Change HTML content
- Change CSS styles
- Handle button clicks
- Validate forms
- Create animations
- Build games
- Communicate with servers (APIs)

JavaScript runs inside web browsers like:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

It can also run outside the browser using **Node.js**.

---

# Why Learn JavaScript?

JavaScript is one of the most popular programming languages because it is used in:

- Frontend Development
- Backend Development (Node.js)
- Mobile Apps
- Desktop Applications
- Games
- APIs
- Full Stack Development

---

# Ways to Add JavaScript

## 1. Inline JavaScript

```html
<button onclick="alert('Hello')">Click Me</button>
```

---

## 2. Internal JavaScript

```html
<script>
    console.log("Hello");
</script>
```

---

## 3. External JavaScript (Recommended)

```html
<script src="script.js"></script>
```

---

# Output Methods

## Console

```javascript
console.log("Hello");
```

Used for debugging.

---

## Alert

```javascript
alert("Welcome");
```

Shows a popup.

---

## Document Write

```javascript
document.write("Hello");
```

Writes directly to the webpage.

---

# Comments
